## Objetivo del Programa
El objetivo de esta aplicación en consola es gestionar la reserva de asientos en una sala de cine representada por una matriz bidimensional (lista de listas) de 3 filas por 4 columnas. El programa permite al usuario seleccionar la fila y columna deseada, valida el estado del asiento y muestra la sala actualizada mediante bucles anidados.

## Cómo ejecutar el programa
1. Asegúrate de tener instalado Python  en tu sistema.
2. Clona este repositorio o descarga el archivo `reserva_cine.py`.
3. Abre una terminal o consola de comandos en la carpeta del proyecto.
4. Ejecuta el programa con el siguiente comando:
   ```bash
   python reserva_cine.py
